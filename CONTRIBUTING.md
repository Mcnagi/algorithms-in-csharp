# Contributing

Contributions are welcome: new structures, more test cases, clearer explanations.

1. Open an issue first for anything bigger than a typo.
2. Branch from `main` (`feature/trie`, `fix/heap-pop-empty`).
3. Add or update tests. `dotnet test` must pass; warnings fail the build.
4. Note the Big-O of every public member in its doc comment.
5. Open a pull request using the template and link the issue.

Please don't submit solutions to the open exercises — they're left for learners.
